# Custom-File-Simulation
Simulates a basic file system using OOP principles. Manages files and directories, allowing users to add files, list contents, and perform file operations. The project is easily extendable for more advanced file system features like search, delete, and modify.
# Custom File System Simulation

## Description
This project simulates a basic file system with classes for `File` and `Directory`. You can add files and list contents of a directory.

## Features
- OOP-based structure
- Add/list files
- Simulates directory storage

## Run
```bash
g++ main.cpp filesystem.cpp -o fs
./fs
